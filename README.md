# React Homework 38

A simple React application created as part of the Hillel FullStack JavaScript course.

The project demonstrates the basics of working with React components, props, and event handlers.

## Features

- React functional component
- Reusable `Button` component
- Props for button text and type
- `onClick` event handler
- TypeScript
- Vite

## Installation

Clone the repository:

```bash
git clone https://github.com/omnimon/hillel_fullstackjs2026_home_task_38_react_initialization.git
```

Navigate to the project directory:

```bash
cd hillel_fullstackjs2026_home_task_38_react_initialization
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## Build

To create a production build:

```bash
npm run build
```
