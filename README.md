# React Homework 38

A simple React application created as part of the Hillel FullStack JavaScript course.

The project demonstrates the basics of working with React components, props, and event handlers.

## Features

- React functional component
- Reusable `Button` component
- Props for button text and type
- `onClick` event handler
- TypeScript
- Vite

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd hw-38-react
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## Build

To create a production build:

```bash
npm run build
```
